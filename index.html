Walk the album numbers

Every Rajče album has a code — a6618931, say. Paste one (or an album link, or a username) and this walks forward through the numbers that follow it, collecting whichever albums are still alive.

Batches per go

Each batch checks 100 codes, so one go walks up to 100 codes before you need to tap again.

This whole stretch is dead — deleted or hidden albums, which is normal for older numbers. Keep walking: the next batch may be livelier, or jump somewhere newer with a random code.

This public edition runs entirely in your browser: it asks Rajče through free public relays (the Jina reader first, then AllOrigins and CodeTabs), because Rajče doesn't answer other websites directly. Relays are shared and rate-limited, so scans run slower than a private server version and the odd album may be missed — a code counted as unchecked can be retried with Next or a fresh scan.
